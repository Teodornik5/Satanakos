# Σατανάκος

Εφαρμογή για Mac που μετατρέπει αρχεία, κατεβάζει από σύνδεσμο και επιλέγει φωτογραφίες. Όλα γίνονται τοπικά στον υπολογιστή σου.

## Τι κάνει

- **Μετατροπή:** βίντεο, ήχος, φωτογραφίες (και HEIC του iPhone) και κείμενα (docx, pdf, txt...). Μπορείς να βάλεις πολλά αρχεία μαζί και κάθε ένα έχει τη δική του μπάρα προόδου. Η ανάλυση δεν αλλάζει ποτέ.
- **Λήψη:** κατεβάζει από σύνδεσμο YouTube ή Instagram ως mp4 ή mp3, στην καλύτερη ποιότητα.
- **Επιλογή:** διαλέγεις φάκελο με φωτογραφίες (και RAW όπως `.arw`), τις βλέπεις μία-μία και πατάς "Κράτα", ή γράφεις πρόθεμα και αριθμούς. Οι φωτογραφίες που κράτησες αντιγράφονται σε νέο φάκελο.

## Εγκατάσταση

Τρέξιμο χωρίς build:

```
pip3 install -r requirements.txt
python3 satanakos.py
```

Φτιάξιμο της εφαρμογής (.app) και ενός zip:

```
bash build_mac.sh
```

Το αποτέλεσμα βρίσκεται στον φάκελο `dist`. Η έκδοση ορίζεται μόνο στη γραμμή `VERSION` στην αρχή του `satanakos.py`.

### Προαιρετικά: LibreOffice

Για τη μετατροπή **κειμένων** (docx, txt, html...) χρειάζεται το [LibreOffice](https://www.libreoffice.org). Όλα τα υπόλοιπα δουλεύουν χωρίς αυτό. Αν λείπει, η εφαρμογή σου το λέει όταν το χρειαστείς.

Η εφαρμογή δουλεύει μόνο στον τύπο Mac όπου έγινε το build (Apple Silicon ή Intel).

## Τρίτα προγράμματα

Η εφαρμογή χρησιμοποιεί, μεταξύ άλλων: [FFmpeg](https://ffmpeg.org) (μέσω του imageio-ffmpeg), [yt-dlp](https://github.com/yt-dlp/yt-dlp), [Pillow](https://python-pillow.org), [rawpy](https://github.com/letmaik/rawpy), [customtkinter](https://github.com/TomSchimansky/CustomTkinter), [pdf2docx](https://github.com/ArtifexSoftware/pdf2docx) και [PyMuPDF](https://pymupdf.readthedocs.io). Κάθε ένα έχει τη δική του άδεια χρήσης. Το FFmpeg που περιέχεται είναι έκδοση με GPL άδεια και το PyMuPDF έχει άδεια AGPL, οπότε δες τους όρους τους αν θες να διανείμεις την εφαρμογή.

## Προσοχή

Η λήψη από YouTube και Instagram μπορεί να παραβιάζει τους όρους χρήσης τους και τα περιεχόμενα έχουν πνευματικά δικαιώματα. Χρησιμοποίησέ την μόνο για προσωπική χρήση.
